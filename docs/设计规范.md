# 水务指标平台 · 前端设计规范

- 版本：v1（定稿）
- 日期：2026-11-02
- 设计立意：**「纯净的一滴水」** —— 冷调亮蓝、清透、明亮、久看不累
- 落地：Vue3 + Element Plus（通过主题变量覆盖 Element 默认蓝，统一到本规范）

---

## 1. 设计立意

水务业务的核心意象是"水"，因此用**一滴纯净的水**作为视觉原点：冷调的亮蓝、清透的渐变、明亮不刺眼。整体走"现代科技感 + 克制清爽"，避免传统政务系统的深蓝和暗色大屏。

三个使用端统一在此立意下，但各有侧重：
- **管理端**：白底为主，清晰高效（配置指标、管权限、查指标）。
- **领导驾驶舱**：冷白渐变底 + 白卡片，明亮大屏（而非暗色大屏）。
- **客户查询端**：轻量聚焦，一个查询入口 + 结果卡。

## 2. 配色 Token

### 2.1 主色系

| Token | 色值 | 名称 | 用途 |
|---|---|---|---|
| `--color-primary` | `#0A84FF` | 清亮蓝 | 主色：按钮、选中态、链接、强调 |
| `--color-primary-light` | `#5AC8FA` | 浅天蓝 | 渐变起点、水滴高光、次级强调 |
| `--color-secondary` | `#0EA5E9` | 青蓝 | 辅助强调、图表次级系列 |

### 2.2 中性色

| Token | 色值 | 名称 | 用途 |
|---|---|---|---|
| `--color-bg` | `#F5FAFF` | 冷白背景 | 页面底色（带轻微蓝调，非暖白） |

| `--color-tint` | `#EAF5FF` | 极浅蓝 | 选中底色、hover 底色 |

| `--color-text-secondary` | `#5B7083` | 灰蓝 | 次要文字、标签、说明 |
| `--color-border` | `#E1EEF9` | 分隔线 | 边框、分割线（带蓝调） |

### 2.3 语义色

| Token | 色值 | 名称 | 用途 |
|---|---|---|---|
| `--color-success` | `#16A34A` | 成功绿 | 达标、通过 |

| `--color-danger` | `#E23D6D` | 警示玫红 | 超标、告警（对比蓝更醒目） |

## 3. 字体 Token

| Token | 值 | 用途 |
|---|---|---|
| `--font-family` | PingFang SC / Microsoft YaHei / -apple-system / Segoe UI | 全局正文 |
| `--font-mono` | SF Mono / Consolas / monospace | 指标编码、数字 |
| 数字处理 | `font-variant-numeric: tabular-nums` | 所有数值对齐、精确 |

字号层级（管理端基准 14px）：

| 层级 | 大小 | 用途 |
|---|---|---|
| 页面标题 | 20px / 700 | 一级标题 |
| 卡片标题 | 14px / 600 | 卡片、区块标题 |
| 正文 | 14px / 400 | 表格、正文 |
| 次要 | 12px / 400 | 标签、说明、表头 |
| 大数字（驾驶舱 KPI） | 30px / 700 | 核心指标值 |
| 大数字（查询结果） | 34px / 700 | 查询主数值 |

## 4. 布局规范

### 4.1 管理端（侧栏 + 内容区）

```
┌─────────┬──────────────────────────────┐
│ 白侧栏   │ 顶栏：面包屑 + 搜索 + 用户       │
│ (220px) ├──────────────────────────────┤
│          │ 内容区：标题 → 统计卡 → 列表/表格 │
└─────────┴──────────────────────────────┘
```

- 侧栏：白底，选中项浅蓝底 + 亮蓝左边框（3px）。
- 内容区：冷白底，卡片用白底 + `--color-border` 描边 + 12px 圆角。
- 统计卡：4 张一行，带水位线。

### 4.2 领导驾驶舱（冷白大屏）

- 背景：`linear-gradient(160deg, #EDF6FF 0%, #F7FBFF 40%, #EAF4FF 100%)`。
- KPI 卡片：白底 + 顶部 3px 亮蓝渐变条 + 轻微蓝投影。
- 图表：白卡片 + 亮蓝水波曲线。

### 4.3 客户查询端（轻量聚焦）

- 顶部一个查询框（指标 / 组织 / 时间），结果卡片展示数值 + 水位线 + 维度下钻 chips。

## 5. 签名元素（记忆点）

### 5.1 水滴图标

CSS 绘制：圆 + 右上尖角（`border-radius: 50% 50% 50% 0` + `rotate(-45deg)`），蓝白渐变，带柔光投影。用于 logo 和品牌标识。

### 5.2 水位线（Waterline）

平台的核心记忆点，三端通用：

- 一条 8px（大屏 14px）高的圆角进度条，填充从底部"涨"起。
- 填充用 `--gradient-water`（亮蓝→浅天蓝），顶部一条高光线（`#D6F1FF`）模拟水面反光。
- 语义：水位高度 = 指标完成度 / 同比 / 占比。
- 动效：数据加载时从 0 涨到目标高度，`cubic-bezier(.22,1,.36,1)` 缓动。

## 6. 组件约定

| 组件 | 规范 |
|---|---|
| 主按钮 | `--gradient-primary` 底、白字、8px 圆角、柔蓝投影 |
| 标签（badge） | 原子指标 = 亮蓝浅底；衍生指标 = 青蓝浅底；圆角 12px |
| 表格 | 白底、表头冷白底灰蓝字、hover 行 `--color-tint` |
| 输入框 | 聚焦时亮蓝描边 + `0 0 0 3px rgba(10,132,255,.10)` 光晕 |
| 指标编码 | 等宽字体、亮蓝色 |
| 维度 chip | 浅底圆角，选中态浅蓝底 + 亮蓝字 |

## 7. Element Plus 主题覆盖映射

在 Vue3 项目中通过 CSS 变量覆盖 Element Plus 默认主题色：

| Element 变量 | 覆盖值 |
|---|---|
| `--el-color-primary` | `#0A84FF` |
| `--el-color-primary-light-3` | `#5AC8FA` |
| `--el-border-radius-base` | `8px` |
| 字体 | `--font-family` |

> 目的：让 Element 组件的按钮、输入框、菜单等默认组件，自动与"清露蓝"规范保持一致，无需逐个定制。
